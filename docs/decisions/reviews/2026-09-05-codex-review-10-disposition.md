alert-policy taint, the fused-call overflow path, the retry of unpaid searches, movement grants, obstacle
validation and the pairwise fight model, plus the history gate.

| # | Finding | Disposition |

| 4 | An unpaid state search after `charge` / `Alarm -> Alerted` / `end_fight` is not retried | **Done (ruleset 16).** Transition and path planning become one step: the state changes only when the search was paid (else the cursor stays on the entity and the transition is retried next tick); `end_fight` keeps a return-pending state instead of resuming patrol on an unpaid search; constructed tests with a near-exhausted states quota. |
| 5 | One accepted movement query (2^20 polygon edges plus index entries) can exceed the movement grant and never progress | **Done (ruleset 16).** The geometry edge limit and the index occupancy per query are bounded so that one atomic query costs strictly less than the minimum movement grant (or the inner progress is persisted); test: maximum geometry and maximum index occupancy with the earlier phases consuming all carry. |
