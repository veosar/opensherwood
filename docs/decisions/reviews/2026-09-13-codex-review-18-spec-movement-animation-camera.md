6. **Blocker — ANIM-101, 305; acceptance test 15 — address: 004c6ef0.** **The cart/human pair test occurs before the element-update pass**, not after updates, queue drain and timers. 7. **Blocker — ANIM-030–031, 120; §3.4; tests 1, 2, 6 — addresses: 005b7300, 005b8050, 005b86b0.** Separate **timer-step behavior from playback-entry behavior**. The play-only path does not step the timer on the call admitting a new action element; the movement path normally does. Thus the raw timer trace in test 1 is not automatically the trace of native 49. A new element requesting the same action ID also differs from an action-ID reset. Specify first-call display, explicit restart, same-action replacement and status precedence. The constants row “extra length … 1” contradicts ANIM-030’s unconditional equal-duration explanation. Mode 10 does not supply the asserted ordinary first-frame duration either: it has no timer-step behavior of its own.

8. **Blocker — ANIM-032, 200, 203; tests 2–3 — address: 005b86b0.** The displacement gate is **timer equals zero after stepping**, not comparison of old and new frame indices. These differ at initialisation, a one-frame wrap and frozen states retaining timer zero. Keep frame-change displacement as an ordinary-cycle description only. Turning’s 0.7 px floor applies **after a nonzero displacement has entered the movement path**; it does not make held, zero-displacement frames creep. With 14 displacement-bearing entries over 32 ordinary cycle updates, the sneak example has **18**, not ten, updates without displacement.

9. **High — ANIM-033, 040–042; play-mode table — address: 005b7820.** Correct **mode 14: it advances forward by two**, not backward. 12. **High — ANIM-003, 131, 134, 210–214; tests 4–5 — addresses: 00464b20, 0055f0f0, 0055f140, 0055f210, 0055f1a0, 0055fc20.** The ordinary shorter-arc rule and counter-clockwise opposite-direction tie are supported.
