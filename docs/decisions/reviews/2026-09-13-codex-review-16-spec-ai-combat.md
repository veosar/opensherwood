1. **Blocker — AI-068, AI-069, section 4, section 7 — `00488f60`, `00488231–00488263`, `00486fa0`.** The accumulator contribution omits a multiplier. The cached floating-point perception value is multiplied by **20 normally, 200 in wide-perception mode**, then truncated. Cached values contribute on intervening frames, not just reevaluation frames. Preserve the floating-point rounding stages in the specification. Delete “a standing hero at half range never accumulates”: with `W = 80` and `g = 0.5`, the contribution is nonzero. This error invalidates the draft’s detection-delay conclusions.

2. **Blocker — AI-100, AI-045, section 7 — `00438620`, specifically `00438624`.** The claimed medium-difficulty uninitialised-variable defect does not exist. The multiplier is explicitly initialised to **1.0**. Hostile actors on easy or hard use **2.0**; medium retains **1.0**. The ordinary delay uses unscaled initiative, the base delay, that multiplier, and an added one before truncation. The multiplication uses a single-precision approximation to `0.01`, so integer-boundary examples require explicit rounding semantics. Retain the separately guarded flat-three-frame exception. Remove every downstream assertion that medium reactions universally take one frame.
